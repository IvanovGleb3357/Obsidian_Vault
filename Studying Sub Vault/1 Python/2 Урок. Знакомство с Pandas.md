## Атрибуты и методы

У атрибутов нет круглых скобок вконце, например: **.shape** - атрибут, а **.head()** - метод.
**Методы** являются функциями, связанными с объектом. Они что-то вычисляют/сохраняют/загружают.

**Атрибуты** — сохранённые признаки, связанные с объектом. Их значение сохранено и не вычисляется при вызове.

Список полезных Атрибутов:
	.shape - данные о размерах таблицы
	.dtypes - типы данных в таблице

Список полезных Методов:
	.describe() - выводит информацию о числе строк, среднем значении, стандартном отклонении, минимуме, максимуме и значениях по 25-му, 50-му и 75-му квартилям.
	.rename(columns={'A B C': 'a_b_c'})
	.sum() - сумма
	.product() - произведение
	.var() - дисперстия
	.std() - стандартное отклонение
	.groupby().agg({'column_name': 'sum'}) - группиорвка и аггрегация
	.sort_values('column_name') - сортировка по возврастанию, есть доп параметр: ascending=True/False
	.value_count() - считает сколько раз встречаеются значения
			Параметры :
			normalize - показать относительные частоты уникальных значений
			dropna - не включать NaN
			bins - сгруппировать количественную переменную, юзер указывает кол-во групп
	.query() - фильтр данных по условию
	.round() - округление
	.strip() - убрать пробелы по бокам
	.replace(' ', '__') - заменить одно, на другое
