## Базовые команды терминала юпитера

	pwd - print working directory
Печать рабочей директории

	ls - list
Выводит файлы и директории в указанной папке

	-lah - используется в дополнение к команде и например для ls -lah  - выведет все содержимое папки с подробной информации о файлах

	cat - concatenate
Выдает содержимое файла

	cd - change directory
Позволяет изменить директорию, перемещаться по папкам

	mkdir - make directory
Позволяет создать директорию

	rm - remove
Позволяет удалить файлы и папки

	git clone link
Колнирует репозиторий с сервера к вам в папку

## Асимметричное шифрфование

Для генерации ключей используется утилита **ssh-keygen**. После этого в папке .ssh будет хораниться пара ключей - публичный (id_rsa.pub) и приватный (id_rsa).

## Текстовый редактор vim

	vi filename
Открыть файл в реадкторе вим

	vi new_filenmae
Создать новый файл в редакторе вим

Для реадктирования файла необходимо нажать **i**.
Это переведет в режим **INSERT**.
Затме можно записать текст и вконце нужно нажать **ESC**.
Для сохранение изменений нажмите **:w** и **ENTER**.
Готово.

	:q + enter
Для выхода из вима

	:wq + enter
Для сохранения и выхода из вима

	python filename.py
Для запуска скрипта в консоле
