## LEFT/RIGHT JOIN

![[Pasted image 20230811133408.png]]
LEFT OUTER JOIN  – возвращаются строки из левой таблицы и соответствующие строки из правой. Как можно заметить, ключевое слово `` `OUTER` `` можно опускать и использовать запись `` `LEFT JOIN` ``.

	![[Pasted image 20230811133451.png]]

## FULL JOIN

![[Pasted image 20230811133536.png]]
FULL JOIN – возвращаются все строки из обеих таблиц.
	![[Pasted image 20230811133555.png]]

## LEFT/RIGHT SEMI JOIN

LEFT SEMI JOIN – возвращает данные только из левой таблички, которые имеют соответствие с правой табличкой. В отличие от `` `LEFT JOIN` ``, колонки из правой таблицы добавлены не будут.

![[Pasted image 20230811134606.png]]

## LEFT/RIGHT ANTI JOIN
LEFT ANTI JOIN – возвращает строки левой таблицы, для которых не нашлось соответствие в правой таблице.

![[Pasted image 20230811134639.png]]

## CROSS JOIN

CROSS JOIN – перекрёстное соединение. С помощью данного объединения мы получаем возможные комбинации значений из первой и второй таблицы.
