## Кортежи

Кортежи(tuple) - неизменяемые объекты, похожи на список, но в отличии от списка потребляют меньше памяти.

Способы объявления:
1. a = (1, 2, 3, 4, 5)
2. a = 1, 2, 3, 4, 5
3. a = tuple(range(5)) - необходимо передать range, список или строку
4. a = () - пустой кортеж

**Операции с кортежем**:
1. len() - длина кортежа
2. print(2 in a) - проверка нахождения элмента в кортеже
3. c = a + b - сложение или сцепление кортежей, порядок имеет значение
4. a * 2 - дублирование кортежей
5. min(a) и max(a) - только если кортеж состоит из только чисел или из только str
7. sum(a) - если из чисел

К кортежам можно обращаться по индексам:
	a[1] и т.д.
	a[1:2]

**Как вносит изменения в кортеж**:
	1. Использование срезов и сцеплений
			a = (1, 'hi', 3, 54, False, 6, 'the', True)
			print(a)
			# хотим изменить индекс 2 на значение 100 
			# и в конец добавить значение 999
			a = a[:2] + (100, ) + a[3:] + (999, )
			print(a)
	2. Преобразовать к списку - > изменение элемента - > преобразовать в кортеж
			a = (1, 'hi', 3, 54, False, 6, 'the', True)
			print(a)
			# хотим изменить индекс 2 на значение 100 
			# и в конец добавить значение 999
			a = list(a)
			a[2] = 100
			a.append(999)
			a = tuple(a)
			print(a)

**Методы кортежей**:
	1. .index() - возвращает индекс элемента в скобках
	2. .count() - возвращает кол-во найденных элементов указанных в скобках

**Добавление объекта** - a[3] = 'Three'
**Удаление объекта** - del a[3]

**Операции со словарями**:
	1. **len()** - длина словаря, кол-во пар: ключ - значение
	2. что-то **in/not** in dictionary() - на выходе True или False
	3. **dict_1 | dict_2** - операция слияния, если ключи совпадают, то предпочтение отдается второму значению

**Методы со словарями**:
	1. .clear() - очищает весь словарь
	2. .get(5, 'No such key') - получает значение по ключу '5', если ключа нет, то делает то что справа, выводит это
	3. .setdefault(7, 'семь') - получает значение ключа, если его нет, то заносит и ключ, и значение
	4. .pop() - возвращает знаечение из словаря по ключу в скобках, а из самого словаря пару удаляет
	5. .popitem(key, value) - удаляет и возвращает пару key - value, по прваилу Последним пришел - первым ушел.
	6. .keys() - возвращает значения ключей
	7. .values() - возвращает значение значений
	8. .items() - возвращает значение коллекции в виде кортежей (ключ - значение)
	9. .update() - обновляет значение словаря другим словарем. При совпадении ключей, записываются значения из переданного словаря

## **Множества**

**Способы создания множнства**:
	1. При помощи фигурных скобок
		a = {1, 2, 3}
	2. Функция set()
		a = set(range(5))
		b = set([1, 2, 3])
		c = set('abcdeabc')
	3. Для пустого множества
		a = set()

Множества можно создать только из **неизменяемых** объектов:
	Строки
	Числа int и float
	Кортежи
	frozenset

**Операции над множествами**:
	1. len() - кол-во элементов
	2. оператор *in / not in*
	3. min(), max()
	4. sum()
	5. sorted()
Также специфические операции:
	6. a & b - пересечение множества
	7.  >, <, = - сравние множества
	8. a | b - объединение множеств
	9. a - b - разность множеств
	10. a ^ b - симмертрическая разность (те элементы, которые есть в одном но нет в другом)
**Методы множества**:
	1. .copy() - копирует
	2. .clear() - удаляет все элементы
	3. .remove('name') - удаляет элемент по имени
	4. .discard('name') - как remove, только если элемента нет, то не выйдет ошибка
	5. .pop() - возвращат и удаляет случайный элемент из множества
	6. .add(5) - добавляет новый элемент в множество
	7. .update() - обновляет множество новыми элементами или множествами
	8. .union() - объединение множеств
	9. .intersection() - пересечение двух множеств
	10. .intersection_update() - пересение двух множеств и результат получает переменая
	11. .difference() - разность множеств
	12. .difference_update() - разность множест + обновление мнж-ства 
	13. .symmetric_difference() - симметричная разность
	14. .symmetric_difference_update()

			- `difference` - `difference_update`;
			- `intersection` - `intersection_update`;
			- `symmetric_difference` - `symmetric_difference_update`;
			- `union` - `update`
