## Аннотации

	first: int = 100
Теперь в эту переменную нельзя записать ничего, кроме int значений. Зачем это нужно? - Ведь нужно подсказывать себе на будущее и другим разработчикам (и даже иногда самому pycharm) с каким типом данных мы хотим работать в определенной переменной.

	def add_numbers(a: int, b: int) -> int:
		  return a + b

Аналогично есть аннотация в функциях. Для того чтобы узнать какой тип данных принимает функция, можно написать:

	print(add_numbers.__annotations__)
