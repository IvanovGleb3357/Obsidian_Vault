1. Вычисления
	Есть 3 типа вычислений:
		- Виртуальные машины
			- (AWS - EC2 - их виратульные машины)
			- (AZURE Virtual Machines)
			- (GOOGLE - Compute Engine)
		- Контейнеры
			- Для множества контейнеров
				- (AWS - EKS Kubernetes servers)
				- (AZRUE - AKS)
				- (GOOGLE - Kubernetes Engine)
			- Для одного
				- (GOOGLE - Cloud Run)
				- (AZURE - Container Instances)
				- (AWS - Fargate)
		- Серверлесс
			- (GOOGLE - Google Cloud Functions)
			- (Azure Functions)
			- (AWS Lambda)
1. Хранилища - для пдф, неструктурированных
	- (AWS - S3)
	- (GOOGLE - Google Cloud Storage)
	- (AZURE - Blob storage)
1. БД
	1. для RDB - кажадый предоставлят разные версии SQL Бд
	2. для NoSQL
		- (AWS DynamoDB)
		- (AZURE CosmosDB)
		- (GOOGLE Firestore/datastore)
	3. для DWH
		- (AWS Redshift)
		- (GOOGLE BigQuery)
		- (AZURE Synapse Analytics)
