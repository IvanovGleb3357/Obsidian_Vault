## SSH (Bitvise SSH Client)
SSH (англ. Secure Shell) — «безопасная оболочка» — сетевой протокол прикладного уровня, позволяющий производить удалённое управление операционной системой и туннелирование TCP-соединений.

## Команды
- ls (список файлов в директории)
- cd - change directory
- mkdir - make directory
- cp - copy file
- mv - move file
- rm - remove file or rename file
- ps - показать процессы
	- ps -ef показатаь все процессы и увдиить кто родитель, а кто последователь процесса![[Pasted image 20240301171035.png]]
- chown auth:auth test.txt
	изменение владельца файла тест.тхт
- chmod 777 test.txt
	максимальные права доступа
	-rwxrwxrwx (read write execute)
	1 - владелец
	2 - пользователь
	3 - через интернет
- su - switch user 
	- su root
- bash, sh, ksh
