dbt - трансформация в одной базе данных, в ELT именно буква T


dbt проект- куча файлов sql, py, yml (конфиги)



dbt при компиляции:
- строит граф (dag) зависимости и автоматом формируется порядок запуска моделей
- делает подстановку вместо функций ref и source:
	- ref - ссылка на модель
	- source - ссылка на объект уже лежащий в базе

Jinja, макросы
- появляется возможность запихивать в sql, циклы, if, переменные, макросы
- {{ }} - переменные, вызо функции
- {% %} - управляющие конструкции (циклы, ифы, макросы)
- {# #} - комментарии

Встроенные материализации:
- view
- table
- incremental (добавление новых записей по ключу)
- ephemernal (в базе ничего не создается, но при ref в родителе появляется cte)
Настраивается в самой модели через {{config(materiliazed='table)}}
