## Операции с матрицей
1. Сложение, вычитание - Можно складывать и вычитать матрицы если они имеют одинаковый размер. Делатся путем сложения и вычитания соответсвующих эллементов.
2. Умножение на число, Деление на число. Тут очевидно. Каждый элеемент умножается, делиться на число.
3. Матричное умножение. Чтобы умножить две матрицы друг на друга, нужно кол-во столбцев первой матрицы должно совпадать с количеством столбцов воторой матрицы. Каждый элемент новой матрицы расчитывается как скалярное произведение соответсвующей строки ппервой матрицы и столбца воторой.

## Решение СЛАУ
- **Метод Гаусса:** Используется для приведения системы линейных уравнений к ступенчатому виду, чтобы затем решить её обратным ходом.
- **Обратная матрица:** Если матрица квадратная и невырожденная (имеет ненулевой определитель), можно найти её обратную и использовать её для решения уравнений вида AX=B, где A — матрица коэффициентов, X — вектор переменных, B — вектор правых частей.
**Обратная матрица:** Матрица, которая при умножении на исходную дает единичную матрицу. Обратная матрица существует только для квадратных матриц с ненулевым определителем.
