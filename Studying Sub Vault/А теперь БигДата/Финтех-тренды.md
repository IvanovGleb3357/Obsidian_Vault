**Dataops** - алертинг по тригерам. Автоматизация, аджайл и observability.

**Datalake** - место хранения данных. Сложная обработка сырых данных для Ml

**Datawarehouse** - для репортинга
**Datalakehouse** - 
	- один интерефейс вместо двух.
	- Разделение compute и storage.
	- ACID в отличии от Datalake. В Datalake сложно писать транзакции и одновременно читать. Писать данные в стриме и читать их сразу.
	- Строгое использование метаданных, управление системой. Защита от превращения DLH в DataSwomp.

**Delta Engines**
	Delta Lake
		Поддержка ACID транзакций 
		Масштабируемая обработка метаданных
		Управления версиями данных (тайм тревел)
		Открытый формат
		Досутп через Spark
	Apache Hodi - поддержка опереаций изменения данных
		То что в Delta
		Индексы для ускорения чтения
	Apache Iceberg - оптимизацая партиционированных таблиц
		Скрытое разбиение на разделы

**Data Governance** - совокупность прецссов поеределния наиболее важных данных для использвания сотрудникми, присвоение им права доступа и управлеиния для отлаженной работы бизнес-процессоа, а также защита данных от внешних возздействия.
	**Metadata Management**. Управление контекстом. Метаданные - информация, которая помогает понять данные и контекст.
	**Data Quality**. Контроль качества данных.
	**Data Security**. Не допускаем утечки данных.
